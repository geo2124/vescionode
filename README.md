# Forge Command Center

Build the initial dashboard shell for a B2B SaaS platform called "Vescio Forge", an AI-native Business-as-a-Service operating system. The application must be dark-mode by default, using Tailwind CSS slate colors (bg-slate-950 for the main background, bg-slate-900 for sidebar and cards) with emerald green (emerald-500) as the primary accent color to give it a premium, industrial, precision-engineered feel.

The layout should have a left-hand navigation sidebar featuring the Vescio Forge logo, an organization switcher dropdown at the top, and menu links for: Command Center, Departments, AI Workforce, Human Approvals, and Settings.

The main central content area should be a "Command Center" dashboard. At the top, include a unified search/command input bar styled like a terminal prompt. Below that, display 4 top-level metric cards: Revenue, Active Leads, Pipeline Value, and AI Tasks Completed.

On the right side of the screen, implement a persistent, vertical "Live Activity Feed" panel. This should look like a scrolling log of system events (e.g., 'Research Agent qualified lead', 'Sales Agent drafted email'), using small icons and timestamps. Keep the UI clean, highly structured, and corporate, avoiding any playful or 'cute' chatbot aesthetics.
